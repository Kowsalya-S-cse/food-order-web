## 📖 Overview

**Foodie Delight** is a client-side food ordering and delivery web application designed to deliver an intuitive culinary browsing and ordering experience. Built with semantic **HTML5**, modern **CSS3** grid/flexbox layouts, and modular **Vanilla JavaScript**, it features dynamic dish rendering, category-based filtering, and a fully interactive modal-based shopping cart with real-time bill calculations.

---

## ✨ Features

- 🍕 **Dynamic Menu Rendering:** Categorized dish catalog featuring pizzas, burgers, sandwiches, and specialties loaded dynamically via JavaScript.
- 🛒 **Interactive Real-Time Shopping Cart:**
  - Add items with instant badge count updates in the navbar.
  - Interactive slide-over / popup modal cart view.
  - Adjust item quantities (+ / -) or remove items with automatic total re-calculation.
- 🔍 **Category Filtering:** Easily filter foods by popular categories (Pizza, Burgers, Sandwiches) for quick navigation.
- 📱 **100% Mobile Responsive:** Optimized with fluid media queries and adaptable grid systems for smartphones, tablets, and desktop displays.
- 💬 **Interactive Contact & Feedback Form:** User-friendly inquiries and message submission interface.
- 🎨 **Modern UI/UX:** Styled using custom CSS variables, hover micro-animations, glass-effect modals, and FontAwesome icons.

## 🛠️ Technologies Used

- **HTML5:** Semantic elements (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`) for accessibility and clean SEO structure.
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, media queries, smooth transition animations.
- **JavaScript (ES6+):** DOM manipulation, event listeners, array methods (`filter`, `map`, `reduce`), state management for cart items, modal controller.
- **Font Awesome 6:** Vector iconography for cart indicators, ratings, and social links.
- **Vercel:** Cloud continuous deployment with global edge hosting.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Kowsalya-S-cse/food-order-web.git
cd food-order-web
```

### 2. Run the Application
Since this is a lightweight vanilla frontend, no complex installations or package managers are required!

- **Option A (Direct):** Double-click `index.html` to open it directly in any modern web browser (Chrome, Edge, Firefox, Safari).
- **Option B (VS Code Live Server):** Right-click `index.html` and choose **"Open with Live Server"** (recommended for live hot-reloading).
- **Option C (Python local server):**
  ```bash
  python -m http.server 3000
  ```
  Then visit `http://localhost:3000` in your browser.
